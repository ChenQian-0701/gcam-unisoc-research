# v0.1.0-alpha.1 — Unisoc GCam research methods

Initial public methodology/tooling release. Includes capability investigation, input/metadata auditing, request/result association, lifecycle failure analysis, privacy review, a device-report schema and fixed-camera SDR output comparison tools.

This repository does not ship a GCam APK or a universal repair module. The initial case study is TYH212U only. Device implementation, exact BSG target, configuration and release artifacts are separately maintained at https://github.com/ChenQian-0701/gcam-tyh212u .

Validation: privacy tests preserve measurement fields while redacting representative identifiers; synthetic output-noise testing checks the known two-to-one noise ratio under brightness/gradient drift. The collector and comparison CLI were also run locally against TYH212U and the owner's supplied samples. These results do not establish compatibility for another device.

Apache-2.0 for original project code/documentation; no proprietary APKs, libraries, raw device dumps, private keys or original photographs are included.
