# Contributing

Please submit small, reproducible changes and state the tested device, firmware, exact GCam APK SHA-256, module commit (if applicable), mode and runtime properties. Separate the requested exposure from actual frame results. A JPEG save, native frame acceptance and shutter recovery are separate observations.

Do not attach full property dumps, private signing keys, proprietary APKs/libraries, full decompiled classes, faces without permission, or images containing GPS metadata. Run the linked privacy tool, then manually review. Redaction is best-effort.

Document negative experiments and limitations. A result on TYH212U does not establish support for another Unisoc phone. Contributions are submitted under this repository's Apache-2.0 license, subject to any clearly identified existing third-party license. Preserve attribution and disclose copied or adapted material.
